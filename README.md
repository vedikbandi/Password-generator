# 🔐 Random Password Generator

A modern and responsive **Password Generator** built using **HTML, CSS, and Vanilla JavaScript**. The application allows users to generate strong, customizable passwords by selecting different character types and password lengths.

---

## ✨ Features

- 🔢 Adjustable password length (1–20 characters)
- 🔠 Include uppercase letters
- 🔡 Include lowercase letters
- 🔢 Include numbers
- 🔣 Include special symbols
- 📋 One-click copy to clipboard
- 📊 Password strength indicator
- 📱 Responsive design
- 🎨 Clean and modern user interface

---

## 🛠️ Technologies Used

- CSS3
- JavaScript (ES6)

## 🚀 Getting Started

### Option 1: Run Directly

Simply open the `index.html` file in any modern web browser.

No installation, backend, or server is required.

### Option 2: Using Visual Studio Code

1. Open the project in Visual Studio Code.
2. (Optional) Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

---

## 📖 How to Use

1. Select the desired password length using the slider.
2. Choose one or more of the following options:
   - Uppercase Letters
   - Lowercase Letters
   - Numbers
   - Symbols
3. Click **Generate Password**.
4. Copy the generated password using the copy button.
5. View the password strength using the strength indicator.

---

## 🔒 Password Strength Indicator

The application visually represents password strength.

| Color | Strength |
|-------|----------|
| 🟢 Green | Strong |
| 🟡 Yellow | Medium |
| 🔴 Red | Weak |

Password strength depends on:

- Password length
- Uppercase letters
- Lowercase letters
- Numbers
- Symbols

---

## 💡 Features Explained

### Adjustable Password Length

Generate passwords between **1 and 20 characters**.

### Character Selection

Supports combinations of:

- Uppercase letters (A–Z)
- Lowercase letters (a–z)
- Numbers (0–9)
- Special symbols

### Secure Password Generation

The application ensures that all selected character types are included in the generated password and shuffles the characters for improved randomness.

### Copy to Clipboard

Instantly copy the generated password with a single click.
